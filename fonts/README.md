# Too Freakin Cute Demo font

- **File:** `TooFreakinCuteDemo.ttf` (from [1001fonts.com: Too Freakin Cute](https://www.1001fonts.com/too-freakin-cute-demo-font.html))
- **Author:** Misti's Fonts
- **Use in app:** `--font-display` (page titles, section headings)

## How to type special symbols

When this font is active, type these characters in decorated titles (see `js/utils/font-decor.js`):

| Key  | Glyph    |
|------|----------|
| `*`  | ♥ heart  |
| `\|` | ☺ smiley |

Example: `*Lernjournal|` becomes ♥Lernjournal☺.
